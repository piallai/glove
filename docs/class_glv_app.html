void GlvApp::show ( const SlvStatus &  _status,

)
static

Show a status widget as a QMesssageBox. Does nothing if GLOVE_APP is not used. _l_wait : if true, the program will not continue until 'Ok' is clicked. Caution, in case _l_wait is false, showing many QMessageBoxes (~40) altogether can produce an overflow.

Check if a QApplication was instantiated. So that method can still be used even if GLOVE_APP is not used.
